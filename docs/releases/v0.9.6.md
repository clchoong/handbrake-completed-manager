# HandBrake Completed Manager 0.9.6

- Refresh now checks the current source file, rather than the output, and highlights unavailable sources in a lighter grey.
- For replaced sources, the check uses the replacement path. A disconnected drive can also make a source appear unavailable; the check does not change media or history.
- Output playback and management remain independent of the source highlight.

The Windows x64 release build and 244 existing automated tests passed, as did portable receiver, shared-storage, and startup smoke checks. The new row highlight has not been visually tested across all Windows configurations.
