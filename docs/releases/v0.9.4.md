# HandBrake Completed Manager 0.9.4

This release improves access to history actions and reduces background work while the application is in the tray.

- Right-click a history row for replacement, playback, file locations, recycling, and history removal. Existing multi-selection is retained when right-clicking a selected row.
- Automatic history refresh pauses while the window is hidden and resumes when reopened. Refresh preserves selection and scroll position when possible.
- History reads and file open/reveal operations run off the user interface thread, and unavailable-file messages suggest checking the drive connection.
- About displays a snapshot of memory use, history count, and the most recent refresh duration.
- **History file** creates a consistent SQLite backup or JSON export without overwriting an existing file. Both can contain private file paths.

Windows x64, Windows 10 build 17763 or later and Windows 11. The release build passed 244 automated tests and portable receiver, shared-storage, and startup smoke tests. Drive or system-wide freezes may have causes outside the application.
