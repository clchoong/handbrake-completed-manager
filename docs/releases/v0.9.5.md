# HandBrake Completed Manager 0.9.5

- The history table has its own scrollbars and corrected visible row numbering.
- A compact details strip stays at the bottom with side-by-side paths and an expandable, independently scrollable details area.
- HandBrake setup is available from the top bar in a closable panel.
- Refresh checks output paths and shades unavailable records grey. A disconnected drive may also make an output unavailable; no media or history is deleted by this check.

The Windows x64 package supports Windows 10 build 17763 or newer and Windows 11. The release build and 244 automated tests passed, as did the portable receiver, shared-storage and desktop startup smoke checks. Interactive visual testing of every layout and drive condition remains outstanding.
